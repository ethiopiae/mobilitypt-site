Our commitment

{{ c.legal_name }} is committed to making this website accessible. We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at level AA.

What we've done

  • Every page can be used with a keyboard alone, with a visible focus outline and a "Skip to content" link.
  • Photos have text alternatives, and we don't put important text inside images.
  • Text and buttons use readable color contrast.
  • Pages use clear headings and labels so they work with screen readers.
  • Pages still work when you zoom in or make the text bigger.
